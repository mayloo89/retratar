# Architecture decisions

One file per decision, numbered, never edited after acceptance. A decision that
turns out wrong gets a new record that supersedes the old one; the old one stays
so the reasoning is still readable.

The format is Michael Nygard's, trimmed: context, decision, consequences. The
consequences section is the one that earns its keep — it is where the cost of
the decision is written down while it is still fresh.

Copy `0000-template.md` to start.
